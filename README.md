# compas_lca

bim-lca integration

## Installation

Stable releases can be installed from PyPI.

```bash
pip install compas_lca
```

To install the latest version for development, do:

```bash
git clone https://github.com/BlockResearchGroup/compas_lca.git
cd compas_lca
pip install -e ".[dev]"
```
