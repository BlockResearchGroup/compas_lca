Project

class compas_lca.project.Project(path, config)

Bases: object

Represents exactly one LCA project rooted at path.

Folder structure is created by the pipeline functions themselves.

enrich_building_data()

Step 04: (Optional) Enrich extracted data with LLM inferences. Controlled via config.yaml flags.

extract_building_data()

Step 03: AI-based extraction of representative data & updated BoQ

classmethod from_config_yaml(config_path=WindowsPath('config.yaml'))
generate_report()

Step 06: Generate impact reports based on matched results. Reads indicators + net stages from config.yaml -> impact_report.

Additionally:

  • For each impacts_*.csv in <project_root>/06_report, generate a summary_*.csv in the SAME directory.

match_with_inventory()

Step 05: Match LcaElements with inventory items. Uses 04_enriched if populated, otherwise 03_extracted. Matching settings are read from config.yaml (with defaults).
