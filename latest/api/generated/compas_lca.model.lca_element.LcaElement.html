LcaElement

class compas_lca.model.lca_element.LcaElement(*, id=<factory>, descriptor, element_core, quantities, metadata, matched_items=None)

Bases: BaseModel

LCA element record (one building-model element mapped to LCA inputs).

Attributes:
idUUID

Stable unique identifier for this element. Auto-generated if not provided (‘uid’).

descriptorElementDescriptor

Descriptive data about the source element (name, types, labels, manufacturer hints, notes). Flags if it is a multilayer, and includes layer count (if multiple layered materials are included in this element).

element_coreList[MatchingCore]

The list of all MatchingCores for each material of this element. Multiple MatchingCore objects if the LcaElement represents a multilayer element Only one MatchingCore if the element is made out of one material.

quantitiesQuantities

Numeric take-offs used for LCA (length, area, volume, piece count, etc.).

metadataOptional[ModelMetadata]

Provenance of the building element (e.g., filename, source software, version, author).

matched_itemsOptional[List[Matches]]

A list of Match objects for each MatchingCore (Matches), representing an abbreviated InventoryItem (attached to the LcaElement after matching and merging). If an LcaElement has multiple MatchingCore objects, each MatchingCore receives the top k matches, and is indexed by the core_id of each MatchingCore. This field is optional, since the same LcaElement object needs to be created before the matching procedure, after which the top_k scored InventoryItems are appended to the matched_items list -> compas_lca/workflows/matching.py

best_score()

Return the best (max score) Match per core_id. Output: { “<core_id_str>”: Match | None }

get_quantity_value(name)

Returns the numeric value of a named quantity from self.quantities.

item_ids()

Return a mapping from each core_id to a list of item_ids found in this element’s matched_items.

item_names()

Return a mapping from each core_id to a list of item_names found in this element’s matched_items.

layer_ratio_map()

Returns {core_id -> thickness_ratio}.

If all (>=2) cores have positive thickness values, ratio = thickness_i / sum(thickness_j). Otherwise (e.g., single-layer or missing thickness), every core gets ratio = 1.0.

matching_core_ids()

Return the element’s MatchingCore core_id values, in the same order as element.element_core has listed them
